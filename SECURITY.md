# Security Policy

## Supported Versions

We actively support and accept security reports for the current `staging` and `main` branches.

| Version | Supported          |
| ------- | ------------------ |
| staging / main | :white_check_mark: |
| < 2.0.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in Lang2Sim, please report it responsibly:

1. **Do not open a public GitHub issue.**
2. Send an email to the repository maintainers or use GitHub's private vulnerability reporting feature:
   - Go to the **Security** tab of the repository on GitHub.
   - Click **Report a vulnerability**.
3. Include detailed steps to reproduce the issue, proof-of-concept payloads or scripts, and impact analysis.
4. Maintainers will acknowledge receipt within 48 hours and work on a fix before public disclosure.
