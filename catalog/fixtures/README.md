# Part 3 fixture runs

Complete run folders (decision 1) used to test the simulation runtime without
waiting on Part 1/2 output. Open one with:

    python scripts/run_sim.py --fixture small_warehouse

| Fixture | World | Source |
| --- | --- | --- |
| `empty_room` | 8 x 6 m room, no obstacles | Generated by Part 1's pipeline (`scripts/fixtures/make_fixtures.py`) |
| `small_warehouse` | 12 x 10 m, four racks, one crate, 2.2 m aisles | Generated by Part 1's pipeline |
| `tb3_world` | TurtleBot3 hexagon world | `world.sdf`, `map.yaml`, `map.pgm` copied from ROBOTIS `turtlebot3_gazebo` / `turtlebot3_navigation2` (Apache-2.0); `spec.json` and `manifest.json` written by the script |

Each `spec.json` carries a mission (initial pose, waypoints, goal) whose points
have at least 0.5 m clearance from obstacles. Regenerate with
`python scripts/fixtures/make_fixtures.py`.
